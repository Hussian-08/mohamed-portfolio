▦ 04

IOT · EMBEDDED SYSTEMS · AUTOMATION

RFID-Based Attendance System

Built an RFID-based attendance system using NodeMCU ESP8266 to automate attendance recording. The system reads RFID cards through the RC522 module, displays attendance status on an LCD, provides buzzer alerts, and sends attendance data to Google Sheets over Wi-Fi. It reduces manual work and demonstrates practical IoT applications for schools and offices.

ESP8266 RFID RC522 Google Sheets Arduino IDE
